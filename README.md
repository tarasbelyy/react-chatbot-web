# Веб-приложение ScAIChatBot


## Описание
Веб-приложение на основе API https://github.com/tarasbelyy/django-chatbot-ai-api


## Инструкция 
Приложение доступно по адресу:
```
https://scaichatbot.3utilities.com
```


## Функциональность
- осуществляется выбор чат-бота и опций сценария диалога
- в конце сессии отображается количество токенов ответа чат-бота
- поддерживается аутентификация и регистрация новых пользователей
- в случае ошибки выводится соответствующее сообщение


## Требования
Основные библиотеки и фреймворки для JavaScript, используемые в проекте: 
- react версии 19.2.8
- react-dom версии 19.2.8
- react-scripts версии 5.0.1
